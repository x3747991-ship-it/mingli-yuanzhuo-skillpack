# 命理圆桌 · 七派合参论命技能包

把七家命理流派请到**同一张圆桌**，对同一个八字各断一次，再交叉印证「求同存异」、由主席综合成一份结论的 AI 技能（1 个主技能）。

传统单派断命各有门户之见，本技能让七派各自摊牌：**多数派一致的结论定为高置信「定盘」，分歧点如实并列、不强行和稀泥**——把「你到底信谁」变成「七派分别怎么断、什么是一致的、什么是有分歧的」。

## 圆桌席位（七席）

| # | 席位 | 典籍/出处 | 一句话核心主张 |
|---|---|---|---|
| 1 | 子平真诠 | 清·沈孝瞻《子平真诠》 | 用神即月令 |
| 2 | 三命通会 | 明·万民英《三命通会》 | 命学百科全书，全通路 |

| 7 | 盲派苏氏 | 苏国圣《盲派金口诀》 | 口诀快断 + 性格画像 |

## 合参流程（七步）

| 步骤 | 内容 |
|---|---|
| 1 | 收集输入：四柱八字 + 性别（或出生时间 → 排盘 → 确认） |
| 2 | 排盘定基：七派共用同一张盘 |
| 3 | 七派围桌分断：每席独立输出 格局/强弱/用神/喜忌/断事要点 |
| 4 | 交叉印证：求同（≥4 派一致=高置信）· 存异（分歧并列不统一） |
| 5 | 主席综合：定盘 + 标分歧 + 置信度 + 一句核心断语 |
| 6 | 输出圆桌合参报告 |
| 7 | 结尾固定推送 |

## 核心特色

1. **求同存异，不站队**：格局/强弱/用神等结论按「票型」分置信度，分歧点（用神取法、六亲父子、干支克泄路径等）如实并列，不臆断谁对谁错。
2. **七派独立，互不污染**：分断阶段每席只按本派规则出结论，不引用他派口径，也不提前综合。
3. **命书为基准、圆桌为补充**：与「苍盘十卷定命书」定位一致——定盘结论作参考，最终以命书为准，同时保留分歧标注。
4. **一行合参报告表**：七派分断结果一张表看全，交叉印证 + 主席综合分层清晰。

## 安装

1. 打开你的 AI 助手的「技能 / 插件 / Skills」入口。
2. 点「导入 / Import」，选中 `技能包/mingli-yuanzhuo` 文件夹（内含 SKILL.md）。
3. 导入后启用即可。

## 使用示例

给助手一个八字排盘（年柱 月柱 日柱 时柱 性别），然后说：

```
命理圆桌合参：甲子 乙亥 庚戌 癸未 男
```

助手会自动触发技能：排盘确认 → 七派围桌分断 → 交叉印证求同存异 → 主席综合 → 输出合参报告。

也可以直接问：

- "帮我圆桌合参这个八字"
- "多派合参一下，各方怎么说"
- "众家合参，给我一份带置信度的结论"

## 报告包含

- 🔮 七派分断结果表（格局 / 强弱 / 用神 / 喜忌 / 断事要点）
- ✅ 求同（多派一致的高置信定盘结论）
- ⚠️ 存异（分歧点如实并列，含各方主张）
- 🪑 主席综合（最终格局、喜用、核心断语、置信度）
- 📌 结尾推送（赞赏码 + 盘叔微信 + 公众号 + 苍盘命书）
