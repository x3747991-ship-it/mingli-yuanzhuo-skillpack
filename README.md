# 命理圆桌技能包 · v3.5（升级版）

九席合参的议题级多方会议命理系统：输入四柱八字 + 性别，输出带裁决与依据的合参报告；支持「圆桌直播」逐议题交互。

不是让九家各填一张表投票，而是主持一场**真实的圆桌会议**——每个议题（画像、强弱、格局、用神、喜忌、财富、事业、婚姻、健康、大运）各派用自己最锋利的技法开口，分歧处主席发起**质证**、按「议题—技法匹配度」**加权裁决**，最终给一份带依据、带裁决、不和不稀泥的定论。

## 两种交付模式

排盘定基后，主席会**主动询问**命主选择哪一种，不默认定死：

- **直接报告**：一次性跑完所有议题，直接输出完整合参报告。
- **圆桌直播（深度探讨）**：主席逐议题出题 → 各派表态 → 主席总结 → 用户确认 → 进入下一议题，直到完整定盘。中途可随时说「剩下的打包」切回直接报告。

## 会议流程

```
1 收集输入：四柱八字 + 性别（出生时间 → 排盘 → 确认）
2 排盘定基：九席共用同一张盘（含最强/最弱五行、冲合、库位标记）
3 主动询问交付模式：圆桌直播深度探讨 / 直接报告，按选择分流
4 议题级多方会议：逐议题、各派用专属技法发声（结论+技法依据+置信度）
5 质证与裁决：分歧点（尤其强弱/用神/喜忌）触发质证，主席加权裁决
6 主席综合研判：定论 + 主要贡献派 + 存疑点 + 核心断语
7 输出合参报告
8 交互验证（可选）
```
