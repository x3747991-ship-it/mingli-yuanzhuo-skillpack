# 命理圆桌技能包 · v2.0（升级版）

七派合参升级为**八席**的议题级多方会议命理系统：输入四柱八字 + 性别，输出带裁决与依据的合参报告。

不是让八家各填一张表投票，而是主持一场**真实的圆桌会议**——每个议题（强弱、格局、用神、喜忌、财富、婚姻、健康、大运）各派用自己最锋利的技法开口，分歧处主席发起**质证**、按「议题—技法匹配度」**加权裁决**，最终给一份带依据、带裁决、不和不稀泥的定论。

## 会议流程（八步）

```
1 收集输入：四柱八字 + 性别（出生时间 → 排盘 → 确认）
2 排盘定基：八席共用同一张盘（含最强/最弱五行、冲合、库位标记）
3 议题级多方会议：逐议题、各派用专属技法发声（结论+技法依据+置信度）
4 质证与裁决：分歧点（尤其强弱/用神/喜忌）触发质证，主席加权裁决
5 主席综合研判：定论 + 主要贡献派 + 存疑点 + 核心断语
6 输出合参报告
7 交互验证（可选）
8 输出结语
```
