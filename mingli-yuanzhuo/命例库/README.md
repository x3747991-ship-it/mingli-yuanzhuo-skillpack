# 命例库 · 录入规范

> 各派「书中命例库」的骨架。各派各自典籍里的命例，按七字段模板逐条录入，作为圆桌「命例匹配」的原型锚点。**命例 > 规则**——遇到原型盘，命例是各派最硬的锚。

## 七字段定义

| 字段 | 定义 | 填写要求 |
|------|------|---------|
| 来源典籍 | 《书名》+ 卷/章 | 必须能回溯到原文，不能只写书名 |
| 原局八字 | 年 月 日 时 + 性别 | 四柱完整；缺时辰要标注「时辰缺」 |
| 书中断语 | 原文断语摘录 | **一字不改，禁止转述** |
| 书中结论 | 富 / 贵 / 贫 / 夭 / 格局 / 用神 | 一句话定性 |
| 议题标签 | 富 / 贵 / 贫 / 夭 / 婚姻 / 疾病 / 性情 | 可多选，用于按议题过滤匹配 |
| 结构特征标签 | 格局 · 最强五行 · 冲合刑穿 · 库位 · 十神组合 | 顿号分隔，作为匹配键 |
| 匹配盘型 | 遇到哪类盘可参照此命例 | 描述性，写清「同型盘」特征 |
| 技法点 | 该命例体现本派哪条技法 | 可关联 SKILL.md 附录A–F |

## 录入铁律

1. **命例必须来自原文，禁止凭记忆编造**——编的命例等于再埋一颗翻车地雷。
2. 八字不完整（缺时辰）可以录，但要在「结构特征标签」里标「时辰缺」，匹配时降级为「相似盘」。
3. 一个命例一条记录，不合并、不概括、不改写断语。
4. 书中命例结论与抽象规则冲突时，**以命例为准**。

## 匹配规则（回顾）

- 优先级：**日时柱相同 > 格局相同 > 冲合相同 > 库位重叠 > 十神重叠 > 最强五行相同**。
- **议题过滤**：先按当前议题筛命例（断财富只匹配富/贫类，断婚姻只匹配婚姻类，断健康只匹配疾病/夭寿类），再打分。
- 命中 ≥2 项结构特征 → 「相似盘」（强参照）；命中 ≥3 项 → 「原型盘」（直接锚定书中结论）。
- 命例 vs 命例冲突时，议题标签匹配度高者优先，仍平手交质证。

## 命学真典 → 命例库 导入对照

命学真典是「蒸馏引擎」：**输入 = 命理书原文**（txt / md / docx / pdf），**输出 = 结构化命例**（命学真典格式）。它的命例提取格式与本库七字段高度同构，按下表转存即可落库：

| 命例库七字段 | 对应命学真典命例的哪部分 | 对应关系 |
|------|------|------|
| 来源典籍 | 「原文位置」（第几章/块）+ 书名 | ✅ 补书名 |
| 原局八字 | 「排盘」年月日时 + 性别 | ✅ 直接 |
| 书中断语 | 「书中论断」（原文摘录） | ✅ 直接 |
| 书中结论 | 「推理链 → 结论」 | ✅ 直接 |
| 技法点 | 「涉及规则」的模型路径 | ✅ 直接 |
| 结构特征标签 | 「排盘」需补算 | ⚠️ 落库时按排盘补算（格局/最强五行/冲合/库位） |
| 匹配盘型 | 无此字段 | ⚠️ 落库时从结论反推「同型盘特征」 |

> **关键前提**：命学真典是工具、不带数据。要填库，**必须有命理书原文作输入**（命学真典第 0 步闸门一：文件在不在）。

## 结构特征标签 · 自动补算规则

「结构特征标签」「匹配盘型」两字段已由脚本对全部 1482 命例自动补算（含滴天髓阐微 508 条），规则如下（后续新增命例按此补算）：

**结构特征标签** = `格局 · 五行旺弱 · 冲合 · 库位 · 十神组合`

| 子项 | 计算规则 |
|------|---------|
| 格局 | 月支本气 → 相对日主的十神 → 格局名（正官格/七杀格/…/建禄格/月刃格） |
| 五行旺弱 | 天干 4 字 ×1 + 地支本气 ×2 + 藏干 ×0.5 加权统计，取最旺/最弱 |
| 冲合 | 四支两两查六冲（去重），无则标「无冲」 |
| 库位 | 辰=水库/戌=火库/丑=金库/未=木库，列出局中所有库 |
| 十神组合 | 其余三天干相对日主的十神 |

**匹配盘型** = `格局 + 最强五行旺 + 冲合`（简化为匹配键）

> 算法为机械计算，不掺人工判断。十神阴阳规则：同五行同阴阳=比肩/食神/偏财/七杀/偏印，异阴阳=劫财/伤官/正财/正官/正印。
