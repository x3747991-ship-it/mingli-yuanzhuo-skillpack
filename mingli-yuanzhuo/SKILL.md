# 命理圆桌 · 九席合参（议题级多方会议，可直播）

## 这是什么

把九家命理席位请到同一张圆桌，但不是让它们**各填一张表然后投票**，而是主持一场**真实的会议**：

- 每一个议题（强弱、格局、取用神、断喜忌、财富……），各派都要用**自己最锋利的技法**开口说话，给出「结论 + 技法依据 + 置信度」。
- 出现分歧（尤其强弱、用神、喜忌这三处最容易翻车的地方），主席**发起质证**——让技法最相关的两派正面交锋，而不是少数服从多数。
- 主席按「议题—技法匹配度」**加权裁决**，最后综合研判，给出一份**带依据、带裁决、不带和稀泥**的最终答案。

一句话：**不是九份表态的堆叠，也不是九票的投票，而是一场让各派技法真正交锋、再被主席收口的圆桌会议。**

## 什么时候用它

- 用户想「多派合参」「多方印证」一个八字，而不是只听一家之言。
- 用户说「圆桌断命」「众家合参」，或想拿子平/盲派/三命/韦千里等流派结论互相对比。
- 用户给了一个八字（或出生时间），要一份综合、带裁决与依据的定性判断。
- 排盘定基后，主席主动询问命主选「圆桌直播深度探讨」还是「直接报告」，按其选择分流执行（模式选择是必经一步，见「会议流程总览」与「模式二 · 圆桌直播」）。

## 什么时候不该用它

- 用户只想问某个具体流派的单点问题（如「用韦千里体系看财运」）——直接触发对应单一技能，不必上圆桌。
- 用户要做「八字版 MBTI」人格测试——那是独立技能（bazi-mbti / mingli-renge-dingwei）。
- 时辰/四柱不明且用户不愿确认——排盘不准则各派全废，先索要准确四柱或出生时间。

### 第 1、2 席的纳音神煞分工（防两席叠床架屋）

第 1 席与第 2 席都涉纳音神煞，但**定位不同**，必须划清边界，避免两席重复发声或互相翻案：

| 维度 | 第 1 席 · 子平纳音体用法 | 第 2 席 · 三命通会 |
|---|---|---|
| 纳音神煞的角色 | **附丽层**：体（格局旺衰）定案后的观感修饰 | **独立断派维度**：与格局、六亲、疾病并列的一条通路 |
| 回答的问题 | 「是什么感觉」——性情 / 气质 / 形貌 / 度量 | 「神煞应什么事、纳音论何命、六亲健康如何」 |
| 能否改判格局 | **否**（铁律：纳音神煞只修饰、不改判、不翻子平的案） | **否**（不得用神煞纳音推翻第 1 席的格局定案） |
| 主发言议题 | 格局成败、用神纯杂、性情气质取象 | 神煞应事、纳音论命、六亲、健康、细节补全 |
| 冲突收口 | 两席纳音取象不一致 → 只作「观感差异」并列，不上升为定性分歧 | 定性分歧按「议题—技法匹配度」裁决：论格局取用 → 第 1 席；论神煞六亲健康应事 → 第 2 席 |

### 第 1、9 席的「体用」分工（防叠床架屋）

第 1 席与第 9 席都谈「体用」「旺衰」，但**第 1 席以月令格局为体、第 9 席以日主旺衰源流为体**，两条路必须分清：

| 维度 | 第 1 席 · 子平纳音体用法 | 第 9 席 · 滴天髓阐微 |
|---|---|---|
| 「体」指什么 | 月令格局（先定格，成败贵贱） | 日主旺衰源流（先定强弱顺逆） |
| 取用路径 | 月令取格 → 顺逆相神 → 用神 | 体用 → 旺极顺势/衰极从势 → 理气进退 |

| 冲突收口 | 论格局成破 → 第 1 席；论旺衰顺逆进退 → 第 9 席 |

## 会议流程总览（两种模式）

本系统支持两种交付模式，共享同一套「排盘定基 → 议题发声 → 质证裁决 → 综合研判」机制，区别只在**交付节奏**。**排盘定基后，主席必须主动询问命主选哪种模式，不默认、不代替用户拍板：**

- **模式一 · 直接报告**：一次性跑完所有议题，直接输出完整合参报告。
- **模式二 · 圆桌直播（深度探讨）**：主席逐议题出题、各派表态、主席总结、用户确认后进入下一议题，直到完整定盘（流程详见下文「模式二 · 圆桌直播」小节）。

```
第一步 收集输入：四柱八字 + 性别（或出生时间→排盘→用户确认）
第二步 排盘定基：排盘并呈现四柱、十神、大运（各派共用同一盘）
第 2.5 步 询问交付模式：主动问命主「圆桌直播深度探讨 / 直接出报告」，按选择分流（直播→模式二，直接→模式一）
第三步 议题级多方会议：逐议题、各派用各自技法发声（结论+技法依据+置信度）
第四步 质证与裁决：分歧点（尤其强弱/用神/喜忌）触发质证，主席加权裁决
第五步 主席综合研判：给出定论 + 主要贡献派 + 存疑点 + 核心断语
第六步 输出合参报告：按议题呈现各派声音 + 裁决 + 最终答案
第七步 交互验证（可选）：把关键分歧摊给用户，由用户专业判断二次确认
第八步 结尾固定推送：赞赏码 + 盘叔微信 + 公众号 + 苍盘命书
```

### 直播规则

1. **逐题确认、不跳题**：10 个议题（画像→强弱→格局→取用神→断喜忌→财富→事业→婚姻→健康→大运）必须逐一走完，用户每确认一题才进下一题。
2. **用户三种回应**：
   - 「确认」→ 记入定盘表，进入下一议题。
   - 点名追问某席 → 该席用本派规则补论一轮，主席重述总结，再次请确认。
   - 指出不符（如「我实际喜火土」）→ 主席标为「待验盘项」，先记存疑、继续推进，最后一并回查。
3. **已定盘沉淀**：每题确认结果即时写入「定盘表」，直播结束即成为合参报告的骨架，不再重跑、不另起炉灶。
4. **随时可切回批量**：用户中途说「剩下的打包 / 直接出报告」→ 未直播的议题按模式一批量补完，最后统一输出完整合参报告。
5. **纠偏优先**：任一题的用户反馈若推翻已确认的定盘项，则受影响议题回滚重跑（与「第七步交互验证」的验盘闭环打通）。
6. **议题清单、发声模板、质证裁决、主席研判**：完全复用本技能「第三步 / 第四步 / 第五步」的既有机制，直播只是把它们**按议题拆开、串进用户确认**，不新增第二套规则。

## 第二步：排盘定基

各派共用同一张盘：

- 年柱以**立春**为界；月柱以**节气**为界；日柱按万年历；时柱分早/晚子时（晚子时按次日日干起时柱）。
- 起月干（五虎遁）、起时干（五鼠遁）；大运阳男阴女顺行、阴男阳女逆行。
- 十神：正官/七杀、正印/偏印、正财/偏财、食神/伤官、比肩/劫财。
- **额外标记**：排出后顺手标出「命主最强五行」「最弱五行」「地支有无冲合刑穿」「库位（辰戌丑未）各属何库」——这四点是盲派发声和财富判断的原料。

### 2.0 调候前置检查（先于旺衰 · 第八席）

调候是比旺衰更底层的约束：同一强弱盘，生腊月与生五月，用神方向可整个相反。凡寒暖燥湿失衡之局，**调候为急，旺衰次之**。

1. **判气候**（快速方向判断）：以月令定寒暖燥湿——
   - 寒（亥子丑月，冬）→ 需火；热（巳午未月，夏）→ 需水。
   - 燥（戌未燥土当令、火土旺而无水润）→ 需水润；湿（辰丑湿土当令、水旺无火晒）→ 需火暖。
2. **查调候表**（精确取值）：依「日主天干 + 月令」查**附录J**，得该盘调候**主神 + 佐神**（如正月甲木 → 主丙、佐癸）。
3. **调候为急判定**：局中无主神，或主神弱而受制（被克、入墓、不透干）→ 调候为急：
   - 用神先取调候主神（如冬金取火、夏金取水），旺衰喜忌让位。
   - 即便身强身弱的旺衰结论与之相反，也以调候为先——「病在气候，不在强弱」。
4. **第八席 · 穷通宝鉴（调候）**：在调候失衡局中，本席为议题三（取用神）、议题四（断喜忌）的主发言席。它不参与旺衰辩论，只裁定「此局调候用什么」。
5. 判定结果写进报告并通知各派：若「调候为急」，则喜忌以调候主神优先，其余各派喜忌均需服从调候。

> 例：金寒水冷之局（冬月金水旺），虽身强喜克泄耗，但调候需火——全局喜火暖局，忌再行水运。

### 2.1 强弱量化刻度尺 + 正格/顺势判定（各派发声前必做）

这一步决定后面「用神、喜忌」走哪条路，是整套系统避免「身强喜克泄耗」教条翻车的保险。**强弱不再各派各说，先过同一把刻度尺。**

**第一步：五行力量计分（全盘统一刻度，消灭「感觉派旺衰」）**

各字计分：天干 = 1 分；地支本气 = 2 分；地支中气 = 1 分；地支余气 = 0.5 分；**月支（月令）本气再额外 +1 分**（月令司权）。

据此算五个五行各自总分，再按十神归类：
- 比劫（同我）分 / 印星（生我）分 / 官杀（克我）分 / 食伤（我生）分 / 财星（我克）分

**第二步：日主强弱判定**

- 帮扶分 = 比劫分 + 印星分
- 克泄耗分 = 官杀分 + 食伤分 + 财星分
- 比值 R = 帮扶分 ÷ 克泄耗分

| R 值 | 强弱档 | 走向 |
|---|---|---|
| R ≥ 2.0 且日主五行 ≥4 字 | 极旺 | 顺势/专旺候选 |
| R ≥ 1.5 | 偏强 | 身强，喜克泄耗 |
| 0.8 ≤ R < 1.5 | 中和 | 视格局取用（旺衰派内部分歧高发区） |
| 0.5 ≤ R < 0.8 | 偏弱 | 身弱，喜生扶 |
| R < 0.5 | 极弱 | 从格候选 |

> 中和档（0.8~1.5）是绝大多数命局的落点，此时旺衰派内部即可分歧——这正是质证该上场的地方，不要硬套强弱。

**第三步：正格 or 顺势/从格**

- **极旺** + 克它者弱到无力 → **顺势**：用神=顺其势，喜生助最强五行，忌克泄耗。
- **极弱** + 帮扶弱到无力 → **从格**：弃命从势，用神=从旺势，喜泄耗克，忌生扶。
- **假从/假专**：极旺但有一字有力克伐，或极弱但有一字有力帮扶 → 非真从真专，按正格论，但须质证。
- 其余 → **正格**，走旺衰路子（身强喜克泄耗、身弱喜生扶）。

判定结果写进报告并**通知各派**：若判「顺势/从格」，旺衰派（子平/韦/神峰/渊海）的「身强喜克泄耗」在本局降级为「存疑意见」，最终以质证 + 大运实证裁决，不得以票数碾压盲派。

> 例：许家印盘（戊戌辛酉己未乙丑）——土 5 字成绝对主角、木火水皆弱 → 判「顺势」→ 旺衰派「喜水木」被大运证伪、盲派「喜火土」应验。

### 2.2 各派命例匹配（原型锚点，防翻车）

抽象规则会翻车（许家印盘各派全错为证），但**书里白纸黑字断过的命例，是各派最硬的锚**。会议前各派先做匹配，五步走：

**① 算新盘的结构特征标签**（与命例库统一算法）：
- 格局 = 月支本气 → 相对日主十神 → 格局名
- 五行 = 天干×1 + 地支本气×2 + 藏干×0.5 加权，取最强
- 冲合 = 四支两两查六冲（去重）
- 库位 = 辰水库 / 戌火库 / 丑金库 / 未木库
- 十神 = 其余天干相对日主的十神

**② 按当前议题过滤命例**（新增，避免张冠李戴）：
- 断「财富」只匹配「富/贫」类命例；断「官贵」只匹配「贵/贱」类；断「婚姻」只匹配「婚姻/克夫/克妻」类；断「健康」只匹配「疾病/夭寿」类；断「性格」只匹配「性情」类。
- 命例库每条命例自带议题标签（富 / 贵 / 贫 / 夭 / 婚姻 / 疾病 / 性情），匹配时先按当前议题过滤，再打分。**三命通会 573 条天然带类，是此步主力。**

**③ 回本派命例库匹配，按权重打分**（高 → 低）：
1. **日时柱相同**（权重最高，命中即强锚定）
2. 格局相同
3. 冲合相同
4. 库位重叠（≥1 库）
5. 十神重叠（≥2 神）
6. 最强五行相同（最宽泛，权重最低）

**④ 命中判定**：
- 日时柱相同 → 「原型盘」，直接锚定书中结论（最高置信）
- 命中 ≥3 项 → 「原型盘」，锚定结论
- 命中 ≥2 项 → 「相似盘」，作强参照
- 命中 <2 项 → 正常按技法推演

**⑤ 命例冲突裁决**（命例 vs 命例，不能并列了事）：
- 两派各命中原型盘、结论相反时，**议题标签匹配度高的那派优先**（断财富时「富/贫」类命例 > 泛类命例）。
- 仍平手 → 触发质证，两派各呈命例原文对质，主席按「该命例与本盘结构相似度」裁决。
- 命例 vs 抽象规则冲突时，**命例优先**，报告标注「命例锚定，非规则推演」。

> **目标：遇到和书中命例同型的盘，该派必须命中、不许推反。** 命例是该派的「标准答案」，优先级高于抽象规则。命中后发言须标注「命例佐证：《XX》有同型命例，断为 X」。

### 2.3 反例防火墙（各派发言前必读）

> 目的：防止各派拿着**已被实证证伪的口诀**重新翻车。以下规则被 1253 例实证库验证为低应验或已证伪，各派引用时必须降级标注，不得作为强论据。

**已证伪 / 低置信规则清单**：

| 规则 | 实证结论 | 处理 |
|---|---|---|
| 「提纲被冲必凶」 | 应验率仅 ~33% | 禁用为强论据；须看冲后是开库还是破格 |
| 「伤官见官，为祸百端」 | 大量反例（财官同宫、伤官生财转生官可化凶为吉） | 降级；须先查有无救应 |
| 「财星弱 / 无财 = 不富」 | 被许家印盘等证伪（财弱而身强食伤旺照样暴富） | 禁用；财富必走五因子 |

**规则引用的硬性要求**：
1. 各派引用一条断语时，**必须标注其应验率**（对接 `G:\A01八字排盘数据库` 202 条实证规则库）。
2. 应验率 < 60% 的规则，发言时标「存疑规则」，不得作为定论依据。
3. 应验率 ≥ 90% 且反证 < 2 条的铁律（如「进气不死」297 验证 / 0 反证），标「铁律」，优先级最高。

> **裁决优先级：铁律 > 普通规则 > 存疑规则**——按此排序，不按票数。

**硬性要求**：

3. 允许并鼓励各派**反驳他派**，但只能基于本派规则，不能拿他派口径当论据。

### 3.3 财富议题的强制五因子模板

断「财富层级」时，**禁止只看财星强弱就下结论**。每派凡涉及财富，必须逐项过这五因子：

> **财富 = 身能否担（势）× 食伤旺否（生财引擎）× 杀印配否（格局名望）× 库冲否（开库取用）× 财星显否（果）**

- 财星（水木等）只是最后落地的「**果**」，不是「**因**」。财星弱甚至无财，不等于不富——只要「身强 + 食伤旺 + 杀印配 + 库冲开」，大运一引财即暴发。
- 同时补判：**命主最强五行 → 宜做哪类行业**（土→地产/基建/矿业，金→金融/制造，水→物流/贸易，木→文教/医药，火→能源/传媒）。

## 第四步：质证与裁决（交互验证）

### 4.1 何时质证

出现以下「框架级分歧」时，**不允许简单并列，必须质证**：

- **取用神**：子平「月令用神」 vs 韦千里「助强扶弱」 vs 滴天髓「体用顺逆」 vs 盲派「不言用神」。
- **强弱**：旺衰派（神峰/韦/子平）判的强弱与盲派直读矛盾时。
- **断喜忌**：喜忌方向相反时（这是最危险的翻车点，务必质证到底）。

### 4.2 怎么质证

1. 主席点名**技法最相关的两派**正面对质。
2. 甲方用本派规则论证，乙方用本派规则反驳，**一轮以上**，直到一方技法露怯或双方僵持。
3. 主席裁决，依据是「**议题—技法匹配度**」，不是票数：

> - 论「库冲取财 / 直读断事」→ 盲派易痴最权威。
> - 论「格局成败」→ 子平纳音体用法最权威。
> - 论「病药 / 干支作用路径」→ 神峰最权威。
> - 论「旺衰源流 / 顺逆进退」→ 滴天髓阐微最权威。
> - 论「用神方向冲突」→ 不能靠票数，要回看命局实际：**此局到底顺谁的逻辑走得通**（例：许家印盘，旺衰派「喜水木」被现实大运证伪，盲派「顺势火土」反而应验）。

### 4.3 裁决输出

每个质证点输出三行：

```
【裁决 · 取用神】
· 正方（子平）：月令用神=…，理由…
· 反方（韦千里）：助强扶弱=…，理由…
· 主席裁：采纳…，因…（技法依据+命局实证）；存疑：…
```

## 第五步：主席综合研判

主席不偏袒任何一席，但**也不和稀泥**，做法是：

1. **定论**：每个议题给出一个明确结论（不是「各有各的说法」，是「本局以X派为准」）。
2. **标贡献**：注明这个结论主要是**哪几派贡献的、用了什么技法**。
3. **标存疑**：真正无法裁决、或需命主验盘的，如实标「存疑」，不硬给答案。
4. **给置信度**：高（定论且多派技法互证）/ 中（定论但存在未决分歧）/ 低（各派僵持，交验盘）。
5. **给全面简析**：把各派分析收敛成「最大概率、最强意象」的断语，逐项输出——性格 / 事业方向 / 财富层级 / 婚姻 / 健康 / 大运，每项一句话点透，最后给命书式核心断语收束。**面向命主，不写系统测试结论、不写内部机制。**

## 附录A：盲派易痴 · 可调用技法规则

> 席位 5 的「武器库」，逐条可调用，用于议题三/五/六/七/八/九的发声。这是整套系统里**唯一覆盖「顺势断用神 / 库冲取用 / 行业五行」的规则集**，权重最高。

### A1. 顺势断用神（最高优先级）

- 判定：日主五行是否已成「绝对主角」（≥4 字、通根带库、克它者弱到无力）。
- 若是：**用神=顺其势**。喜 = 生助最强五行的五行 + 最强五行本身；忌 = 克泄耗最强五行的五行。
  - 例：土金两旺 → 喜火（生土）土（本体）金（吐秀），忌水（财，被劫）木（杀，虚浮被金克）。
- **反例警示**：旺衰派「身强喜克泄耗」在顺势盘上系统性失灵——走财星（忌神）大运不但不富，反而水土相战、破财伤身。

### A2. 库冲取用（开库）

- 辰戌丑未为四库：辰=水库、戌=火库、丑=金库、未=木库。
- 库被冲（丑未冲 / 辰戌冲）→ **开库取用**：库中藏物（食神/七杀/印/财）全部释放参与作用，是「暴发」的机制。
  - 例：丑未冲 → 丑中辛金（食神）出库生财、未中乙木（杀）出库配印 → 杀印相生、食神生财两路齐开。
- **双刃**：开库既是暴发的引擎，也是暴败的祸根——库冲之命多**大起大落**，非平稳之富。

### A3. 杀印相生

- 七杀透干（纵无强根）而局中有印（藏干即可）→ 杀不攻身，反生印、印生身，是「名望、权力、格局」之源。
- 判富贵时，杀印相生比「财星多少」更关键：**「势」的富贵靠杀印+食神，不靠财星**。

### A4. 行业五行

- 命主最强五行 → 宜做对应行业：土→地产/基建/矿业/农业，金→金融/机械/制造/冶金，水→物流/贸易/互联网，木→文教/医药/纺织，火→能源/餐饮/文化。
- 判「事业·行业」议题时以本派为准（其余六派多不覆盖此维度）。

### A5. 宫位断六亲/灾祸

- 日支（夫妻宫）被冲 → 婚姻有波折、聚少离多。
- 印星（母）藏而不透、又逢冲损 → 母缘薄、母早逝之象。
- 年月相穿（如酉戌穿）→ 早年坎坷 + 埋下「违规、账目」类隐患。
- 七杀被食神制太过 → 晚年官非、牢狱之灾象。

### A6. 十二长生断运

- 日主/用神在大运的十二长生状态定吉凶：走「长生/临官/帝旺」则顺，走「墓/绝/死」则衰。
- 例：土金两旺局走「庚辰」运，辰为金之墓、土多金埋 → 食禄丧失、败象。

## 附录B：子平纳音体用法 · 可调用技法规则（子平为体＋纳音神煞为用）

> 席位 1 的「武器库」。核心：**先以子平定「有没有 / 能不能」，再以纳音神煞修饰「是什么感觉」**。发言必先报「XX格 + 成/破 + 身强弱」，其后补纳音取象与神煞层次。**铁律：格局成败贵贱一律以子平为准，纳音神煞绝不改判、绝不翻案。**

### B1. 体 · 日干旺衰（得时失时 × 党众助寡）

- 得时为旺、失时为衰；党众为强、助寡为弱。合看四态：**旺而强 / 旺而弱 / 衰而强 / 衰而弱**。
- 通根轻重：长生禄旺 > 余气 > 墓库；**月令之支为根最重**；干多不如根重。
- 阳干从气不从势（略有根即不从）、阴干从势无情义（财官偏盛则从）。

### B2. 体 · 月令取格 + 顺逆（定格）

月支本气（司令之神）相对日主定十神格 → 正官格 / 七杀格 / 正财格 / 偏财格 / 正印格 / 偏印格 / 食神格 / 伤官格 / 建禄格 / 月刃格。

- **善神顺用**（财、官、印、食，宜生扶护持）：财格宜食伤相生、忌比劫夺财；官格宜财生官印护官、忌伤官克官；印格宜官杀生印、忌财坏印；食格宜身旺生财、忌枭夺食。
- **恶神逆用**（杀、伤、刃，宜制化）：七杀格宜食制、无制则灾；伤官格宜佩印、忌见官（见反例防火墙）；羊刃格宜官杀制刃、无制则凶。
- **相神**：辅佐用神者（官格透财、财格身弱逢印）。用神得相神辅 = 成格；被忌神破 = 败格。

### B3. 体 · 用神五法 + 成破判定

- 取用五法：**扶抑 / 病药 / 调候 / 专旺 / 通关**，皆从月令推定。
- 成：用神透干有力、得相神辅、不被忌神克破；败：用神被克泄破（财见比劫、官见伤官、印见财、食见枭、杀无制）。**有病方为贵**（有病有药方贵）。

### B4. 用 · 纳音取象（是什么感觉）

体既定案后，再以纳音修饰性情气质，**只润色、不改判**：

- **位置**：日柱纳音主「才器度量、形貌」（最贴身）；年柱纳音主「祖上出身」；胎元纳音主「先天禀赋」。
- **五行性情**：水多沉潜多权、火多崇礼明外昏内、木多柔懦聪明、金多刚直好胜、土多厚重守密。
- **具象**：六十甲子纳音三十位（海中金韬光、剑锋金外露、钗钏金藏锋待用……）；自生自旺纳音主精气自足、休囚死绝主气薄晚发。

### B5. 用 · 神煞辅助（层次微调，不可翻案）

- 天乙贵人、干禄、驿马、天月德、文昌——在子平「成格」之上做「锦上添花」、在「破格」之下做「稍有体面」的微调。
- **铁律**：子平判「贱格」纵带天乙贵人，仍以「虽带贵而不成格」论，**不得翻案称贵**。

> 速查：纳音三十位取象、五行互乘性情表、神煞细目见 `子平纳音体用法/references/子平法_旺衰十神格局用神.md` 与 `纳音神煞辅助.md`（本技能包以子平为体、纳音神煞为用；与三命通会席位的纳音神煞分工，见「圆桌席位」小节的『纳音神煞分工』表）。

## 附录C：神峰通考 · 可调用技法规则（病药八法）

> 席位 3 的「武器库」。核心：**命有一病，必有一药**；先点病，再开药，用神即药。

### C1. 四病

- 雕：物已成器而待雕琢（如金多需火炼、木成材需金琢）。
- 枯：物已枯槁而待滋润（如木枯需水、火熄需木）。
- 旺：某神过旺为病（日主过旺无依、官杀过旺、财过旺）。
- 弱：某神过弱为病（日主过弱、用神过弱）。

### C2. 四药

- 损：损其有余（旺者泄之克之，身旺用食伤 / 官杀 / 财）。
- 益：益其不足（弱者生之扶之，身弱用印 / 比）。
- 生：以印生身、生用神。
- 长：以比劫帮身、长用神。

### C3. 病药断法

1. 点病：全局最大失衡点（最旺或最弱的一处）。
2. 开药：能制衡此病者即用神。
3. 判吉凶：有药且药有力 = 吉；有病无药 = 凶；药被病克 = 药失效。

### C4. 动静说

天干为动、地支为静；动作用于静（透干之干可作用于地支藏干）。看干支作用路径，勿只看表面。

## 附录D：韦千里 · 可调用技法规则（评断八步 + 行运折衷）

> 席位 6 的「武器库」。核心：**用神=助强扶弱**，与子平「月令用神」是两条路，议题三必质证。

### D1. 评断八步（按序走）

1. 强弱（日主旺衰）→ 2. 格局（月令定格）→ 3. 用神（助强扶弱）→ 4. 六亲 → 5. 女命（专论）→ 6. 性情（五行性情）→ 7. 富贵 → 8. 吉凶（大运流年）。

### D2. 助强扶弱

- 身强 → 用神=克泄耗（官杀 / 食伤 / 财）。
- 身弱 → 用神=生扶（印 / 比劫）。
- 用神在八字中「有根有气」才有力，虚浮无力则用而不显。

### D3. 行运折衷法

- 喜神运吉、忌神运凶，以大运干支对照原局用神喜忌。
- 看大运与原局的合冲刑害（合则化、冲则动、害则损）。
- 折衷：喜忌混杂时取折中，看是喜多还是忌多。

### D4. 日时配置断法（《八字提要》精髓，1440 条之要）

> 韦千里《八字提要》按「日干 × 月令 × 时辰」逐格断，核心是**日时配置的即时生克**。调候总纲与附录 J 一致（以附录 J 为准），此节补其独有维度——「日干坐支 + 时干作用」。
